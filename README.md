# cc-random-programs
Just some random programs for the Minecraft mod "CC: Tweaked"!

# Install It
```lua
wget https://raw.githubusercontent.com/azb19111/cc-random-programs/refs/heads/main/programs/INSTALL.lua
```

To run it, use
```lua
shell.run('INSTALL')
```
in a lua file.
If you want to run it once the system starts, use:
```lua
edit startup.lua
shell.run('INSTALL')
```
Do not forget to save the file.
